# DB Bench Progress

A small offline phone app (PWA) for tracking and progressing dumbbell bench press: log sessions (Heavy / Medium / R / Deload), see history and an e1RM chart, and get a "Next session" recommendation (heavy/medium undulation, RIR targets, double progression, deload trigger). Weights are per dumbbell, lb.

## Install on Android (Chrome)
1. Open https://mkedean-310.github.io/bench-app/ in Chrome.
2. Menu (⋮) → **Add to Home screen** / **Install app**.
3. Launch it from the home screen; it works offline.

## Backup
Data lives only on your phone (browser storage). Use **History → Export backup** regularly to save a JSON file; **Import backup** restores it.

See the in-app **Method** tab for the rules and sources. Not medical advice.
